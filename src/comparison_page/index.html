Logistic Regression

A simpler linear model. Numeric attributes are scaled, categorical attributes are one-hot encoded, and each feature receives a learned weight.

ROC AUC 0.937953
Log loss 0.233580

Best when you want a conservative, explainable, better-calibrated probability baseline.

CatBoost

A gradient-boosted tree model. It handles categorical attributes natively and can learn thresholds, nonlinear effects, and feature interactions.

ROC AUC 0.940719
Log loss 0.320222

Best when the scoring goal rewards ranking likely buyers above unlikely buyers.

Same Data, Different Shape

Logistic regression adds weighted feature effects together. CatBoost builds many decision trees, so it can react differently to combinations of attributes.

Where CatBoost Jumps Higher

It often rewards rows with low range anxiety, home charging, available subsidy, and shorter commute. These combinations are easier for tree boosting to capture.

Where Logistic Stays Higher

It gives smoother additive credit to features such as high environmental concern and longer commute. That can make it less sensitive to learned thresholds.

Practical Choice

Use CatBoost for ROC AUC style ranking. Use logistic regression if the target metric is log loss or if easier explanation is more important.
